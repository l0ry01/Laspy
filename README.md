# Laspy
Ukázka práce s knihovnou Laspy v Pythonu

Cíl projektu: 
Projekt představuje možnosti knihovny Laspy pro načítání, prohlížení a základní zpracování LiDARových dat ve formátu LAS/LAZ.

V rámci projektu si ukážeme:

- Načítání a prohlížení mračna bodů.
- Práci s klasifikací bodů.
- Výběr terénních a vegetačních bodů.
- Vytvoření digitálního modelu terénu (DTM).
- Vytvoření modelu vegetačního povrchu (DSM).
- Výpočet modelu výšky vegetace (CHM – Canopy Height Model).
